# Aionis v0.3.7 Evidence-Gated Learning Candidate

Aionis Runtime v0.3.7 is a Local Runtime Public Beta candidate for one
self-hosted process. It adds protected, append-only evidence authority for
learning episodes and direct memory feedback. It does not claim a mature
autonomous-learning loop and does not enable candidate serving globally.

## What Changed

- Added append-only learning episode, experiment, namespace-lease,
  exposure-item, feedback-attribution, safety-stop, and operation-receipt
  authority under the main SQLite transaction runner.
- Added atomic v3-to-v4 migration plus strict current-schema, restart, backup,
  restore, source-commit, and receipt-root verification.
- Added non-HTTP protected experiment provisioning and close with strict
  reviewed input, OS-CSPRNG matched-pair assignment, exact replay, bounded HMAC
  approval, Runtime receipt attestation, and all-or-nothing lease release.
- Added optional guide `operation_id` with exact concurrent/lost-response
  replay, conflict rejection, and a 2 MiB receipt limit.
- Persisted memory/tool decisions, guide receipt, learning exposure/items, and
  protected operation receipt in one transaction.
- Added strict `host_task_envelope_v1` and `host_use_receipt_v1` roots. Direct
  feedback validates the exact guide, episode, run, operation, subject set,
  served surface, outcome, verifier, content evidence, and evidence reference.
- Made direct-memory activation, feedback event/attribution, derived strength,
  counters, safety pause, and gate-authority receipt one atomic write.
- Added `@aionis/sdk@0.3.16` builders, parsers, digest helpers, and protected
  identity forwarding, plus a bounded read-only host conformance command.
- Kept all 21 registered HTTP routes inside the route-governance matrix and
  measured complexity after new source files are tracked.

## Safety Posture

- `AIONIS_ADMISSION_CANDIDATE_POLICY_MODE` remains off by default.
- Legacy unprotected feedback remains compatible but is promotion-ineligible
  and cannot contribute formal gate coverage.
- The production external-execution-policy registry remains unregistered and
  the gate-policy registry remains `calibration_pending`.
- Confirmatory and active-control production traffic do not start
  automatically.
- At the immutable v0.3.7 checkpoint, the learning-control queue table and
  integrity contract were reserved, while Task 4.1 Step 4 enqueue, leasing,
  retry/dead-letter worker, and Runtime startup/shutdown wiring were not yet
  present. Current post-v0.3.8 mainline includes them. Repeated-unused remains
  distinct from negative feedback: only the durable worker may apply the
  bounded inspect-before-use posture after recomputation.
- Tool-feedback atomic refactoring, measurement episode binding, and later
  evidence-gate/promotion phases remain future work.

## Compatibility

- Existing unprotected guide and feedback payloads remain accepted.
- HTTP and SDK contracts add optional protected fields; no route is removed.
- A complete v3 authority database migrates atomically to v4. A damaged, mixed,
  or future schema fails closed before business writes.
- SQLite remains the durable authority for the supported single-process Lite
  deployment. Multi-instance HA and managed multi-tenant GA are not claimed.
