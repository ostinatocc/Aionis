# Aionis v0.2.2

Aionis v0.2.2 cleans up the public Runtime boundary after the package split.
The Runtime repository now ships the Runtime only; SDK, MCP, installer, and
Claude Code plugin surfaces live in their own repositories and npm packages.

## What Changed

- Removed vendored `packages/` sources from the Runtime repository.
- Removed vendored Claude Code plugin files from the Runtime repository.
- Removed workspace build/test scripts from the Runtime release path.
- Added Runtime-only CI guards so adapter package sources do not drift back into
  the Runtime repo.
- Updated external package smoke tests to install published package specs instead
  of packing local workspaces.
- Updated command-posture Runtime e2e so MCP behavior is validated through the
  external package smoke path, not by importing MCP source from the Runtime repo.
- Updated docs and release boundaries to point at standalone repositories:
  - `ostinatocc/aionis-create`
  - `ostinatocc/aionis-sdk`
  - `ostinatocc/aionis-mcp`
  - `ostinatocc/aionis-claude-code`

## Installer Compatibility

Use `@aionis/create@0.2.4` or later with this Runtime release. That installer
runs the Runtime root build script and no longer calls the removed
`packages:build` workspace script.

Fresh install smoke was validated against the split Runtime tree:

```bash
AIONIS_FRESH_INSTALL_CREATE_SPEC=@aionis/create@latest \
npm run -s runtime:smoke:fresh-install
```

## Verification

The release was validated with:

```bash
npm run -s typecheck
npm run -s lite:test
npm run -s runtime:e2e:command-posture
npm run -s runtime:smoke:external-packages
npm run -s runtime:smoke:fresh-install
```

## Docker

Run the published Runtime image:

```bash
docker run --rm \
  -p 127.0.0.1:3001:3001 \
  -v aionis-data:/data \
  ghcr.io/ostinatocc/aionis:v0.2.2
```

## Notes

- Runtime source, Docker, product APIs, docs, examples, and Runtime validation
  loops remain in `ostinatocc/Aionis`.
- SDK/MCP/installer/plugin packages release independently.
- This release keeps the local-first Runtime path intact while removing package
  compatibility baggage from the Runtime repo.
