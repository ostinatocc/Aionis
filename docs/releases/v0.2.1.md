# Aionis v0.2.1

Aionis v0.2.1 formalizes the Runtime release surface: source release, Docker
image, npm packages, SDK, MCP bridge, and release runbook.

## What Ships

- Aionis Runtime source for local-first execution memory.
- Dockerfile and compose file for local Runtime deployment.
- GHCR publishing workflow for `ghcr.io/ostinatocc/aionis:<tag>`.
- Release documentation that explains source, Docker, npm, SDK, MCP, and Server
  mode artifacts.
- Product positioning updates from the v0.2 line: execution memory, Memory
  Firewall, Agent Flight Recorder, admission policy, and state-preserving
  context compression.

## Docker

Run the published Runtime image:

```bash
docker run --rm \
  -p 127.0.0.1:3001:3001 \
  -v aionis-data:/data \
  ghcr.io/ostinatocc/aionis:v0.2.1
```

Health checks:

```bash
curl http://127.0.0.1:3001/healthz
curl http://127.0.0.1:3001/readyz
```

## npm Packages

Use npm for Agent integrations:

```bash
npx @aionis/create@latest
npm install @aionis/sdk
npx @aionis/mcp@latest --base-url http://127.0.0.1:3001 --scope-from workspace
```

## Notes

- Docker Lite mode is intended for local or loopback-bound deployments.
- For remote SDK/MCP clients, use Server mode with API-key or JWT auth.
- Aionis keeps retrieval and governance separate: external memory backends can
  keep recall, while Aionis governs what becomes Agent context.
