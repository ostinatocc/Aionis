# Aionis v0.3.10 Development Baseline

Aionis Runtime v0.3.10 is the current development train. No v0.3.10 Runtime
tag, Docker image, or GitHub release is claimed by this document.

## Included Development Work

- Task 5.1 makes tool-selection feedback one atomic SQLite attribution unit:
  external preparation runs before the transaction, current decision and rule
  facts are revalidated inside it, the final response is protected by an exact
  operation receipt, and external effects run only after commit.
- The train binds `@aionis/sdk@0.3.18` to immutable source `v0.3.18`.
- The train binds `@aionis/manifest@0.1.1` to immutable source `v0.1.1`.
- Runtime and Docker CI resolve Manifest from the train, verify its exact
  checkout and package, and run the real Manifest resume integration without a
  configured-environment skip path.
- Existing v0.3.9 durable learning-control queue and worker behavior is
  preserved.

## Evidence Boundary

This baseline establishes auditable exposure-to-feedback persistence. It does
not yet bind verified measurements back to episode pairs, calibrate the formal
evidence gate, or authorize autonomous promotion. Task 6.1 and later evidence
phases remain outside this checkpoint; global candidate serving remains off.

Historical v0.3.9 evidence is retained verbatim in
