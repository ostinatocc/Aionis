# Aionis v0.3.5 Release Candidate

Aionis v0.3.5 is the aggressive AgentContext compaction repair for the v0.3
stable Runtime train.

The immutable v0.3.4 tag preserved Runtime latency, product loops, governance,
and safety, but its aggressive guide projection was larger than the frozen
pre-refactor comparator. This patch restores the intended compact contract
without changing public APIs or SDK types.

## What Changed

- Aggressive standard and full-power guide requests now use the canonical
  bounded contract renderer.
- Compact route, evidence, and governance lines retain the active target and
  required safety boundaries without carrying verbose duplicate projections.
- Guide-only target files remain visible when a selected current memory has no
  target-file projection of its own.
- Candidate CI now reads the standalone SDK source ref from
  `release-train.json`; this patch reuses the stable SDK `0.3.14` contract.

## Verification

- SDK and structural checks passed 66 / 66.
- TypeScript Runtime tests passed with 818 passes, zero failures, and four
  optional Zvec skips on the validation host.
- Runtime complexity stayed within the committed budget: 283 source files,
  120,747 source lines, 19 route entries, 177 environment fields, and zero
  import cycles.
- Mean projected context was 37.18% smaller than immutable v0.3.4 and 14.55%
  smaller than the frozen pre-refactor comparator, with recall, stale-leak,
  rehydration, audit, and Memory Firewall outcomes unchanged.
- The full 40-case five-arm external context-stability run completed 40 / 40.
  Aionis retained 40 / 40 accepted direction, zero wrong attention, zero wrong
  writes, and zero rediscovery while using 74.82% fewer prompt tokens and
  84.15% fewer initial-context characters than Full History.

The current external host shifted Aionis, Full History, BM25, and Mem0 to
`rehydrate` rather than executable edits. That cross-arm action-completion
result remains inconclusive and is not presented as an Aionis-only regression
or a completed tool-execution gate.

## Release Safety

- Runtime v0.3.4 remains immutable.
- SQLite remains the Runtime truth source.
- Zvec and Substrate remain governed candidate/sidecar sources.
- No public Runtime or SDK contract changes in this patch.
- Create 0.3.7 must not be published until Runtime `v0.3.5` and its Docker image
  resolve because the installer selects that immutable tag by default.
- No package or image is considered published until exact-version smoke tests
  pass.
