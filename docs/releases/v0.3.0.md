# Aionis v0.3.0

Aionis v0.3.0 is the stable baseline release train for the public Runtime and
integration packages.

## What This Release Delivers

- Runtime source, Docker image, product APIs, docs, examples, and Runtime
  validation loops in `ostinatocc/Aionis`.
- Unified public package train:
  - `@aionis/sdk@0.3.0`
  - `@aionis/create@0.3.0`
  - `aionis@0.3.0`
  - `@aionis/mcp@0.3.0`
  - `@aionis/aifs@0.3.0`
  - `@aionis/claude-code@0.3.0`
- Guided install through `npx aionis setup`.
- Docker Runtime image `ghcr.io/ostinatocc/aionis:v0.3.0`.
- Optional Zvec ANN candidate sidecar while SQLite remains the Runtime fact
  source and Aionis governance remains the final admission layer.

## Product Surfaces

- **Execution Memory Runtime**: preserve plans, decisions, validation evidence,
  outcomes, handoffs, and rehydrate pointers across sessions, agents, models,
  and devices.
- **State-Preserving Context Compression**: compile long execution history into
  shorter, cleaner, auditable Agent context.
- **Memory Firewall**: govern internal or external memory candidates before
  they influence an Agent.
- **Agent Flight Recorder**: replay what memory was shown, suppressed,
  restored, or acted on.
- **AIFS / MCP / SDK / Native Adapters**: connect Aionis through files, MCP,
  TypeScript, HTTP, and host-specific lifecycle hooks.

## Install

```bash
npx aionis setup
```

Docker:

```bash
docker run --rm \
  -p 127.0.0.1:3001:3001 \
  -v aionis-data:/data \
  ghcr.io/ostinatocc/aionis:v0.3.0
```

## Verification

Release validation should include:

```bash
npm run -s typecheck
npm run -s lite:test
npm run -s runtime:smoke:external-packages
npm run -s runtime:smoke:fresh-install
docker build -t aionis:release-smoke .
```

## Notes

- Runtime source, Docker, product APIs, docs, examples, and Runtime validation
  loops remain in `ostinatocc/Aionis`.
- SDK, CLI, installer, MCP, AIFS, and Claude Code adapter packages release from
  their standalone repositories.
- `@aionis/substrate` remains an experimental sidecar/research package at
  `0.1.0` and is not part of the v0.3.0 stable train.
