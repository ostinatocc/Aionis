# Aionis v0.3.0

Aionis v0.3.0 is the first stable public baseline for compact, governed
execution memory.

The release is built around one product claim: long-running Agents should carry
the execution state that matters, not drag the whole history forward. Aionis
turns plans, decisions, validation output, accepted routes, blocked
alternatives, rehydrate pointers, and feedback evidence into a shorter,
cleaner, auditable context object that can survive sessions, Agents, devices,
and model switches.

## What This Release Delivers

- Runtime source, Docker image, product APIs, docs, and Runtime validation
  loops in `ostinatocc/Aionis`.
- Unified public package train:
  - `@aionis/sdk@0.3.0`
  - `@aionis/create@0.3.0`
  - `aionis@0.3.0`
  - `@aionis/mcp@0.3.0`
  - `@aionis/aifs@0.3.0`
  - `@aionis/claude-code@0.3.0`
- Guided install through `npx aionis setup`.
- Docker Runtime image `ghcr.io/ostinatocc/aionis:v0.3.0`.
- Optional Zvec ANN candidate sidecar while SQLite remains the Runtime fact
  source and Aionis governance remains the final admission layer.

## Why It Matters

Agent memory is useful only when the next Agent can tell what is current, what
is stale, what is evidence-only, and what needs raw rehydration. Aionis makes
that boundary explicit:

- `use_now`: accepted state the Agent can act on.
- `inspect_before_use`: relevant evidence that needs checking.
- `do_not_use`: blocked or invalidated memory that must not become instruction.
- `rehydrate`: compact pointer to raw detail when the Agent needs more evidence.

That contract lets Aionis preserve continuity without turning every old trace
into prompt mass.

## Product Surfaces

- **Execution Memory Runtime**: preserve plans, decisions, validation evidence,
  outcomes, handoffs, and rehydrate pointers across sessions, agents, models,
  and devices.
- **State-Preserving Context Compression**: compile long execution history into
  shorter, cleaner, auditable Agent context.
- **Memory Firewall**: govern internal or external memory candidates before
  they influence an Agent.
- **Agent Flight Recorder**: replay what memory was shown, suppressed,
  restored, or acted on.
- **AIFS / MCP / SDK / Native Adapters**: connect Aionis through files, MCP,
  TypeScript, HTTP, and host-specific lifecycle hooks.

## Evidence Surface

The strongest current evidence is context-cost robustness: Aionis aims to keep
full-history-level execution continuity while compiling a smaller, governed
context. The public evidence stack includes:

- MGBench for deterministic memory-governance scenarios.
- State-preserving context compression reports.
- External-agent continuation runs with full-history, BM25, Mem0, and Aionis
  arms.
- Admission dataset export and real-agent rerun infrastructure for measuring
  memory influence.

These reports support the current product direction: stronger candidate
retrieval below, strict admission governance above, and auditable memory
influence throughout.

## Install

```bash
npx aionis setup
```

Docker:

```bash
docker run --rm \
  -p 127.0.0.1:3001:3001 \
  -v aionis-data:/data \
  ghcr.io/ostinatocc/aionis:v0.3.0
```

## Notes

- Runtime source, Docker, product APIs, docs, and Runtime validation loops
  remain in `ostinatocc/Aionis`.
- SDK, CLI, installer, MCP, AIFS, and Claude Code adapter packages release from
  their standalone repositories.
- `@aionis/substrate` is tracked separately as an external sidecar package. It
  is not part of the v0.3.0 stable Runtime train and is not a Runtime
  dependency.
