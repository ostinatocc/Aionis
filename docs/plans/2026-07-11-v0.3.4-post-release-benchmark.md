# Aionis v0.3.4 Post-Release Benchmark Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Prove whether the released Aionis Runtime `v0.3.4` preserves product quality, safety, context efficiency, and same-machine performance relative to the frozen pre-refactor baseline and the previously published benchmark evidence.

**Architecture:** Run benchmarks from isolated Git worktrees so the immutable release and the pre-refactor comparator use the same host without changing Runtime product code. Store every new raw artifact in a versioned post-release directory, compare same-run A/B results instead of unrelated historical absolute latency, and separate deterministic local gates from network/model-cost gates.

**Tech Stack:** Node.js 24, TypeScript/TSX, Lite SQLite, the existing Runtime E2E harness, AionisRuntime-evals, MGBench, optional native Zvec, JSON/Markdown benchmark artifacts.

## Acceptance gates

| Surface | Gate |
|---|---|
| Runtime-only total-loop P50 | Same-machine regression no greater than 10% in the conservative order-controlled comparison |
| Runtime-only total-loop P95 | Same-machine regression no greater than 10% in the conservative order-controlled comparison |
| Runtime product loops | No failed loop and no missing required contract surface |
| External Agent completion | 40/40; no regression from the frozen report |
| External Agent accepted direction | 40/40; no regression from the frozen report |
| External Agent prompt tokens | No more than 5% above 650,482 unless quality evidence justifies and documents the increase |
| MGBench active-state recovery | 100% |
| MGBench unsafe direct-use | 0/40 |
| MGBench rehydrate and trace coverage | 100% |
| State-preserving compression | Compression at least 70%, current-state recall at least 95%, stale leak at most 2% |
| Downstream action accuracy | Not below Full History and no material drop from the prior 95.8% Aionis result |
| Negative transfer | No failed/stale/private memory promoted into direct use |
