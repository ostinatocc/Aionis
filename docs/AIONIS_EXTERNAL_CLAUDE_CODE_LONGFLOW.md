# Aionis External Claude Code Long-Flow Case

This document records a real external Agent host case using Claude Code with the
published Aionis Claude Code hook package. It is separate from the internal
Runtime product verification flow in `scripts/e2e/long-flow-product-demo.ts`.

## What Was Run

The case used an isolated sandbox project:

```text
/Volumes/ziel/aionis-claude-external-longflow-20260627-121522
```

The project contained a small Node test suite and a route-state implementation.
Claude Code was invoked twice with `claude -p` in two separate sessions:

1. Episode 1 fixed failing route-state tests in `src/routeState.js` and ran
   `npm test`.
2. Episode 2 started a new Claude Code session, received Aionis context before
   the prompt, continued the same active implementation surface, added tax
   behavior, updated tests, and ran `npm test` again.

The Runtime was an isolated local Lite process on `127.0.0.1:3197` with SQLite
data stored under the sandbox directory.

## Aionis Integration Surface

Claude Code was connected through:

- `@aionis/claude-code@latest`
- local Claude Code hooks in `.claude/settings.local.json`
- local MCP registration named `aionis-external-case`
- workspace scope generated by the Aionis Claude Code integration

`aionis-claude-code doctor` returned:

```text
ready: true
runtime_ok: true
hooks: local installed
mcp: installed
```

## Result

The case passed.

Episode 1:

- Aionis `SessionStart` and `UserPromptSubmit` hooks ran.
- Claude Code edited `src/routeState.js`.
- `npm test` passed.
- Aionis recorded Bash/Edit outcomes and a verified session handoff.

Episode 2:

- A new Claude Code session received `AIONIS_EXECUTION_MEMORY_CONTEXT`.
- The injected context included:
  - `ACTIVE_TARGETS`: `src/routeState.js`
  - `SHOULD_CONTINUE`: the prior active implementation route
  - `DO_NOT_USE`: the earlier failed validation command as blocked evidence
  - validation evidence from `npm test`
  - verified implementation route text
- Claude Code continued `src/routeState.js`.
- `src/legacyRouteState.js` stayed unchanged.
- `npm test` passed with 3 tests.

After episode 2, a direct Runtime guide call with the same workspace/task context
reported:

```text
history_used: true
actionable_history_used: true
target_files:
  - test/routeState.test.js
  - src/routeState.js
use_now_memory_ids: 4
do_not_use_memory_ids: 1
```

## Product Meaning

This is the first external Claude Code long-flow case for the v0.3 line. It
shows that Aionis can sit beside a real Agent host, inject compact governed
execution context before a later session, and record tool outcomes into an
auditable Runtime trail.

It should not be presented as an external benchmark or broad task-success
claim. It is a host-integration case proving the product loop works outside the
Runtime's own E2E harness.
