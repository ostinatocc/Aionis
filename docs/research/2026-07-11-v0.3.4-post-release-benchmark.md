# Aionis Runtime v0.3.4 Post-Release Benchmark Decision

Date: 2026-07-11

## Decision

**The immutable `v0.3.4` tag is classified as regression; the remediation
candidate `e5cc4dcbfdca88421b3c5e0fceeb579c52c25e2a` is locally validated and
has positive external-pilot evidence, but its full promotion gate remains
inconclusive.**

The release preserves same-machine latency, product loops, governance, and
safety. It nevertheless regressed aggressive context compaction by 36.02%
versus the pre-refactor comparator. The fix reduces mean projected context by
37.18% versus the release and 14.55% versus the comparator without changing
recall, leak, rehydration, or audit outcomes.

The approved 10-trap, three-arm external pilot on the fix completed 10/10,
matched Full History on accepted direction and wrong-branch safety, and reduced
rediscovery from five steps to one. It used more tokens than Full History and
does not satisfy the original 40-case, five-arm acceptance gate.

## Performance result

The two order-controlled rounds establish Runtime-only P50/P95 non-regression
for the release. Context output and SQLite footprint were effectively equal in
this no-embedding workload. Maximum RSS changed from +39.90% when the release
ran first to -9.11% when it ran second, so the high-water result is
order-sensitive and inconclusive rather than a stable memory regression.

## Product and safety result

Provider-backed and deterministic product loops preserve continuity recovery,
actionable memory after writes, failed-branch isolation, tenant/team/private
visibility, feedback attribution, positive measured impact, and read-only
operator evidence. The fresh single-agent fixture contains a pre-existing
semantic assertion that expects history on an empty scope; both revisions
produce the correct negative-control response. No benchmark-only correction
was retained in Runtime source.

The released compaction regression was isolated to render selection and compact
contract projection, not state adjudication. The fix keeps every measured
quality and firewall surface unchanged while reducing projected context.

## External pilot result

The approved DeepSeek pilot used 10 ready real-source traps, three arms, one
seed, and the frozen `evidence` episode-2 mode. It produced 30 arm results with
no runner failure. Aionis matched Full History on the two safety/quality
headlines and reduced repeated discovery, but increased tokens.

Total usage was 378,040 prompt tokens and 33,397 completion tokens. The
configured-price estimate is $0.0623, not a provider receipt. The report
contract passed with no required failure; three publishable enhancement files
remain optional and absent.

## Release disposition

1. Do not describe the immutable `v0.3.4` tag as fully non-regressed; its
   aggressive context projection is measurably larger than the comparator.
2. Treat `e5cc4dc` as the remediation candidate. Its Runtime structural/SDK
   gate passed 66/66 and TypeScript Runtime tests passed 822/822, with no source
   budget relaxation.
3. The evidence is sufficient to merge/release the narrowly scoped compaction
   repair if the release criterion is the reproduced regression plus full local
   verification and the approved three-arm pilot.
4. If the original benchmark plan remains the binding promotion contract, run
   the unchanged-model 40-case five-arm Agent/MGBench suite before claiming a
   complete post-release pass.

This wording deliberately separates product evidence from external repository
task success: the demonstrated Aionis effects are continuity, reduced repeated
discovery, correct state selection, and negative-transfer blocking.
