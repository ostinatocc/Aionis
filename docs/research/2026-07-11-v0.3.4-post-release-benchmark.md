# Aionis Runtime v0.3.4 Post-Release Benchmark Decision

Date: 2026-07-11

## Decision

**The immutable `v0.3.4` tag is classified as regression; the remediation
candidate `e5cc4dcbfdca88421b3c5e0fceeb579c52c25e2a` passes local validation and
the 40-case five-arm external context-stability gate, but the strict executable
action-completion gate remains inconclusive because the run froze manifest and
script hashes without freezing the multi-step rehydrate-continuation control.**

The release preserves same-machine latency, product loops, governance, and
safety. It nevertheless regressed aggressive context compaction by 36.02%
versus the pre-refactor comparator. The fix reduces mean projected context by
37.18% versus the release and 14.55% versus the comparator without changing
recall, leak, rehydration, or audit outcomes.

The subsequent strict 40-case, five-arm run completed 40/40 with no retained
runner failure. Aionis preserved 40/40 accepted direction, zero wrong-branch
attention or writes, and zero rediscovery while using 74.82% fewer prompt
tokens and 84.15% fewer initial-context characters than Full History. However,
Full History, BM25, Mem0, and Aionis all shifted from historical executable
actions to cautious `rehydrate` exits, so action completion fell to zero across
all four memory arms. Retained decision artifacts also show that `rehydrate`
terminated immediately; the harness default disables continuation unless
`AIONIS_E2E_REHYDRATE_CONTINUES` is explicitly enabled. Because the historical
reports did not record that control, protocol equivalence is unproven. This
prevents attributing the completion change to the Runtime fix or solely to the
model host and prevents a strict action-completion pass.

## Performance result

The two order-controlled rounds establish Runtime-only P50/P95 non-regression
for the release. Context output and SQLite footprint were effectively equal in
this no-embedding workload. Maximum RSS changed from +39.90% when the release
ran first to -9.11% when it ran second, so the high-water result is
order-sensitive and inconclusive rather than a stable memory regression.

## Product and safety result

Provider-backed and deterministic product loops preserve continuity recovery,
actionable memory after writes, failed-branch isolation, tenant/team/private
visibility, feedback attribution, positive measured impact, and read-only
operator evidence. The fresh single-agent fixture contains a pre-existing
semantic assertion that expects history on an empty scope; both revisions
produce the correct negative-control response. No benchmark-only correction
was retained in Runtime source.

The released compaction regression was isolated to render selection and compact
contract projection, not state adjudication. The fix keeps every measured
quality and firewall surface unchanged while reducing projected context.

## Full 40-case five-arm result

The strict follow-up used the historical 40-record manifest, the historical
five arms (`no_memory`, `full_history`, `bm25_retrieval`, `mem0`, `aionis`),
`episode2-source=base`, and `deepseek-v4-flash`. The frozen manifest SHA-256 is
`eb687cecc1b14fe6e5b996905ee2e121ade39d4feb21d4a2eeb8beb11377dd3b` and the
agent script SHA-256 is
`8ff69b1a20109d1a8bff53ec1218fcdc814db49948c92a96346b7ad7510fac5c`;
both exactly match the 2026-06-28 comparator.

The first continuation resumed from 21 successful records after a transient
report-directory `EACCES`. The harness now archives the pre-resume JSONL and
normalizes the canonical checkpoint to successful, in-scope, unique trap IDs.
A later host-level `SIGBUS` stopped both local Qdrant context construction and
the Runtime; after memory pressure recovered, the same checkpoint logic kept 37
successful records and the final three completed. The canonical final report
contains 40 unique successful rows, all with five complete arms. Neither
infrastructure incident is retained as a product failure.

Aionis passed every difficulty cell: 10/10 accepted direction, zero wrong
attention, zero wrong writes, and zero rediscovery for `tidy`, `separated`,
`implicit`, and `buried`. Relative to the historical Aionis run, prompt tokens
fell 69.18% and completion tokens fell 55.92%, but every arm used materially
fewer tokens in the current provider run. Those historical token deltas are
therefore descriptive, not attributable solely to the Runtime fix. The
same-run comparisons against Full History, BM25, and Mem0 are the valid budget
evidence.

The action-completion detector is the remaining blocker. Historical Aionis,
BM25, and Mem0 completed 40/40 executable actions and Full History completed
39/40; the current run recorded 0/40 for all four. Decisions instead selected
`rehydrate`, and retained traces show that action ended the agent instead of
continuing as a tool step. The manifest and agent script are byte-identical,
but the historical and current reports did not freeze
`AIONIS_E2E_REHYDRATE_CONTINUES` or the rest of the model request controls.
The collapse across every memory arm still does not isolate an Aionis
regression, but it also cannot be attributed solely to provider behavior or
used to claim executable-task non-regression. Close the gate with a
provenance-fingerprinted rerun that explicitly enables continuation and records
the requested and returned model identity.

## Release disposition

1. Do not describe the immutable `v0.3.4` tag as fully non-regressed; its
   aggressive context projection is measurably larger than the comparator.
2. Treat `e5cc4dc` as the remediation candidate. Its Runtime structural/SDK
   gate passed 66/66 and TypeScript Runtime tests passed 822/822, with no source
   budget relaxation.
3. The evidence is sufficient to merge/release the narrowly scoped compaction
   repair if the release criterion is the reproduced regression, full local
   verification, external route safety, continuity, and context-budget
   non-regression.
4. Do not claim a complete external tool-execution pass from the current host
   run. If executable action completion remains a binding promotion criterion,
   rerun the same frozen matrix with the corrected provenance-fingerprinted
   harness and require 40/40 Aionis action completion. If the provider does not
   expose an immutable snapshot, describe the model as version-labeled rather
   than weight-immutable.

This wording deliberately separates product evidence from external repository
task success: the demonstrated Aionis effects are continuity, reduced repeated
discovery, correct state selection, and negative-transfer blocking.
