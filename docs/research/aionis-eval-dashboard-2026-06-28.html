Result 6 — Backend-Agnostic Memory Firewall

Aionis does not require replacing your existing memory backend. The Memory Firewall sits between retrieval and the Agent prompt, routing retrieved candidates through use_now, inspect_before_use, do_not_use, and rehydrate before they become instructions.

Methodology Boundaries

These results are intentionally bounded:

  • External Agent E2E measures context stability and continuation behavior on a specific 40-case set. It is not a general GitHub issue-solving benchmark or a claim about all coding-agent tasks.
  • MGBench measures memory governance under interference. It does not measure broad LLM reasoning, patch correctness, or task-specific success rates.
  • State-preserving compression is an internal benchmark with deterministic scoring plus downstream LLM scoring. It is not a public external benchmark.
  • Memory Firewall A/B is a 12-scenario product evidence snapshot, not a broad market comparison with Mem0.
  • Admission dataset results prove the flywheel and policy-evaluation path; they do not certify a learned admission policy for broad rollout.
  • Zvec results are recall-quality diagnostics; enabling Zvec does not change Aionis admission semantics.
  • Filtered competitor modes receive governance from the external host, not from the memory system itself. Governance ownership is recorded separately.
  • All competitor results come from public releases or standard API configurations. No unfair advantage is intended.
