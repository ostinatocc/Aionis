## Result

| Arm | Runs | Accepted direction | Wrong-branch action | Rediscovery steps | Prompt tokens | Completion tokens | Total tokens |

Aionis reduced rediscovery by 80% versus Full History and by 75% versus No
Memory. It removed the No Memory arm's one wrong-branch action and one missed
accepted direction. Aionis prompt tokens were 5.36% above Full History and
12.71% above No Memory; total tokens were 8.35% and 11.30% higher,
respectively. This pilot therefore supports a continuity/action-efficiency
claim, but not a token-reduction claim.
